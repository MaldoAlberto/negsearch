# QOBLIB-based instances (maximum independent set)

Source: QOBLIB, problem class 07-independentset — https://github.com/ZIB-AOPT/QOBLIB
Data license: CC BY 4.0. Please cite: T. Koch et al., "The Quantum Optimization Benchmarking Library",
Nature Computational Science 6, 653–671 (2026), doi:10.1038/s43588-026-00991-1.

- `farm.gph`, `mammalia-kangaroo-interactions.gph` (+ `.opt.sol`): original QOBLIB instances (unchanged).
- `*-sub18.gph`: induced 18-vertex subgraphs of QOBLIB instances (changes stated in each file header),
  selected so that deterministic min-degree greedy is NOT optimal.
